Challenge The Portland Rafting Company would like a program to manage its daily operations of providing customers with personalized bamboo raft trips on the river lasting 1, 2 or 3 hours. Three packages are offered, which provide extras along with the trip on the river, the: • Scenic Tour (base cost - US$119), which includes stopping for drinks or snacks • Relaxation Tour (base cost - US$139), which includes stopping at popular landmarks or for photos • Joyous Fun Tour (base cost - US$149), which allows for swimming. The number of hours determines how many different landmarks (in the case of the Relaxation Tour), the length of the drink/snack stop (in the case of the Scenic Tour) or the length of time spent swimming (in the case of the Joyous Fun Tour). In addition to the package cost, each hour spent on the trip attracts a cost of US$20.

Write the pseudocode for a program that will accept a series of records. Each record contains a customer ID, customer name, the number of hours that the customer would like to spend on the trip and the type of package selected. Based on the package type and the number of hours, the program should determine the cost of the trip for EACH customer. Output for the program consists of the customer ID, customer name and the cost of the trip for each customer. It should also output the total number of customers processed for the day and the overall total cost of all trips made by customers on any particular day. The program should use -1 for the customer ID to signal that no more records are to be processed. Assume valid input.
